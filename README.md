# MasterO

Локальное macOS-приложение для подготовки приложений к публикации по чеклистам. Минимальная версия рассчитана на macOS 26 и использует SwiftUI, SwiftData и MVVM.

## Структура

- `Models.swift` — модели приложения, шаблона и пунктов.
- `ChecklistRepository.swift` — операции хранения и копирование пунктов шаблона в приложение.
- `ApplicationViewModel.swift` — загрузка данных и команды для интерфейса.
- `ContentView.swift` — боковой список приложений и выбранный чеклист.
- `EditingSheets.swift`, `TemplateManagerView.swift` — создание и редактирование приложений, шаблонов и пунктов.

Пункты шаблона и приложения хранятся независимо. Изменение шаблона не меняет уже созданные приложения. Общий статус приложения выбирается вручную.

## Открытие проекта

Откройте `MasterO.xcodeproj` в Xcode и запустите схему `MasterO`. Настройка генерации проекта находится в `project.yml`.
