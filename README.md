# CheckTuk

Локальное macOS-приложение для подготовки приложений к публикации по чеклистам. Минимальная версия рассчитана на macOS 26 и использует SwiftUI, SwiftData и MVVM.

## Структура

```text
MasterO/
├── App/                         # Запуск CheckTuk и подключение базы
├── Data/                        # Репозитории и доступ к SwiftData
├── Domain/
│   ├── Models/                  # Модели приложения, шаблонов и пунктов
│   ├── ValueTypes/              # Типы данных для редактирования
│   └── Transfer/                # Формат импорта и экспорта шаблонов
├── Presentation/
│   ├── ViewModels/              # Состояние экрана и пользовательские действия
│   └── Views/                   # Экраны по функциям приложения
│       └── Tips/                # Окно подсказок и JSON-документ
└── Assets.xcassets/             # Иконка приложения
```

`Presentation/Views` разделён на `Applications`, `Settings`, `Templates`, `Tips` и `Workspace`. Настройки внешнего вида хранятся в `UserDefaults`. Шаблоны и подсказки можно переносить между установками приложения в JSON. Импорт подсказок добавляет тексты к уже сохранённым.

## Обновления и сохранение данных

Приложение использует версионируемую схему SwiftData в `Data/CheckTukSchema.swift`. Версия 1 описывает прежние модели, версия 2 добавляет подсказки и содержит лёгкий этап миграции. Перед каждым следующим изменением модели нужно добавить новую версию схемы и этап миграции, сохранив предыдущие версии без изменений. Не удалять и не переименовывать поля или модели без явного перехода миграции. Идентификатор пакета `com.checktuk.app` и расположение хранилища должны оставаться стабильными: установка новой сборки через DMG тогда заменяет приложение, а локальные данные продолжают храниться в контейнере приложения. Настройки в `UserDefaults` также требуют сохранения существующих ключей либо отдельного переноса значений.

Перед выпуском DMG нужно проверять обновление на копии данных предыдущей версии: открыть приложение после замены, убедиться в наличии приложений, чеклистов, шаблонов, подсказок и настроек, затем проверить возможность продолжить сохранение данных.

Пункты шаблона и приложения хранятся независимо. Изменение шаблона не меняет уже созданные приложения. Общий статус приложения выбирается вручную.

## Открытие проекта

Откройте `CheckTuk.xcodeproj` в Xcode и запустите схему `CheckTuk`. Настройка генерации проекта находится в `project.yml`.
